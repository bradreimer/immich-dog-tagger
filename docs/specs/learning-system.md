# Learning System

## Purpose
Use human feedback to improve classification.

## User Story
After reviewing photos, future classifications should become more accurate.

## Goals
- Store embedding examples
- Preserve provenance
- Improve nearest-neighbor classification

## Non-goals
- Any local model training or fine-tuning

## Requirements
- Store embeddings
- Track source
- Associate examples with identities

## Open Questions
How should example quality and provenance influence reference selection?
